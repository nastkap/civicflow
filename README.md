# CivicFlow

CivicFlow is a web-based system for managing citizen requests and service cases.

The system allows citizens to submit requests, track their status and communicate with the responsible department. Employees can review, assign and process requests, while administrators can manage users and system configuration.

## Main Features

* User registration and authentication
* Role-based access control
* Citizen request creation and management
* Request assignment and status management
* Comments and request history
* Notifications
* User and category administration
* REST API
* Responsive web interface

## User Roles

### Citizen

* Create requests
* View own requests
* Track request status
* Add comments

### Employee

* View and manage assigned requests
* Update request status
* Add comments
* Review request history

### Administrator

* Manage users
* Manage request categories
* Manage system configuration
